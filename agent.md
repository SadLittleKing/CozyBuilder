## Task routing
- Create a new Codex project task for each new game feature.
- Send fixes, refinements, and extensions of an existing feature to the task that built it.
- Check existing task titles and summaries to find the owner before routing work.
- Give a new task the relevant game context and decisions. Coordinate work in the shared project directory so two tasks do not edit the same files at once.
- Keep design discussion in the current conversation and report completed work back here.
